Detailed Description

Represents an abstract logger.

This class can be inherited to create a logger type that can be logged to.

The logger includes a logging thread, and a mutex to guarentee thread safety. The logging thread calls Update() which can be implemented in whatever way, but is intended to sync the log to the log medium.
