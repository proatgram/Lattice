Detailed Description

Abstraction over a Cache file.

A Cache file for Lattice is similar in format to INI/TOML, but much more simpler. Ultimately you do not need to know the format in order to write and read from it.

Each cache context can have sections, which are either normal sections or array based sections that are iteratable.
