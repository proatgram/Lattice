\doxysubsection{Detailed Description}
Handles dependency resolution. 

Through the use of instance tracking, \doxylink{classLattice_1_1Object_1_1Resolver}{Resolver} can access every created resolvable entity and attempt to resolve it, making the resolved object accessible directly to the consumer of the dependency.

Attempts to resolve all available declared dependencies. 

This function will run through all of the \doxylink{classLattice_1_1Object_1_1Resolver}{Resolver} instances and try to resolve each of them from ID to \doxylink{classLattice_1_1Object_1_1Object}{Object}. It aggrigates a list of dependencies that failed to resolve, and returns it if there are any failures. If there are none, then the default-\/constructed return type is returned to the caller.

\begin{DoxyReturn}{Returns}
An expected value of void on success. A list containing the \{identifier, reason\} for resolution failure on fail. 
\end{DoxyReturn}
