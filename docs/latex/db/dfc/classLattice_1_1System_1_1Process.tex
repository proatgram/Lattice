\doxysubsection{Detailed Description}
Represents a process on the system. 

Represents a process on the system that can:
\begin{DoxyItemize}
\item Be ran
\item Be waited for
\item Provide all 3 output streams (out, in, err)
\item Provide run info (exec time, exit code, \doxylink{classLattice_1_1System_1_1Command}{Command})
\item Be cancelled. 
\end{DoxyItemize}
