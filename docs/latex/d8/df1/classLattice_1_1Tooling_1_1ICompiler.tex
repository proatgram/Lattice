\doxysubsection{Detailed Description}
Abstract Compiler interface. 

This class can be extended to add different compilers to \doxylink{classLattice_1_1Lattice}{Lattice}.

Compilers are configured based on how they are called in the command line and how they are configured in \doxylink{classLattice_1_1Lattice}{Lattice} configs and in source. To add a new compiler, inherit from this class, and implement the {\ttfamily \doxylink{classLattice_1_1Tooling_1_1ICompiler_a1fd803309ba5268cb7039e8e61493ff9}{Create\+Command}(..)} method and the {\ttfamily Create\+Configuration(...)} methods to create a method of obtaining your specific compilers command calls and configurations.
