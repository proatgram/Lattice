\doxysubsection{Detailed Description}
A simple registry. 

A registry is a singleton, obtained by calling {\ttfamily \doxylink{classLattice_1_1Registry_a2c06dba6c8deec4215ce10794aeaf5b4}{Get\+Instance()}} on the registry. The registry can have contain elements of any type, but the key is always a string.

A \doxylink{classLattice_1_1Registry}{Registry} element is unique and forceful. If you try to register something that already exists, it will not overwrite it, and will give an error.
